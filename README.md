# Papan Skor Pokédex Light Combo — Trainer Stadium & TCG 3D

Papan skor interaktif Pokédex Light Combo dengan dukungan 3D Avatar Roblox, TCG Card effects, dan API terintegrasi untuk Vercel.

## Fitur Utama
- **Theme Pokédex Light & TCG 3D**: Desain modern bertema Pokédex & Trainer Stadium.
- **Render 3D Roblox**: Tiga model 3D Three.js interaktif.
- **API Serverless**:
  - `/api/cari-roblox`: Pencarian avatar & profil Roblox
  - `/api/cookie-roblox`: Validasi & status cookie Roblox
  - `/api/auto-add-friend`: Fitur auto pertemanan Roblox
  - `/api/roblox-friend`: Manajemen friend request
  - `/api/roblox-3d-model`: Asset avatar 3D Roblox
